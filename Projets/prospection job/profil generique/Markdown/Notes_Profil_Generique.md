## ⚙️ Comment cibler une offre à partir de ces fichiers

1.  **Dupliquer** le dossier `profil generique` ou copier les fichiers HTML dans le sous-dossier de la nouvelle entreprise (ex: `prospection job/nom-entreprise/`).
2.  Dans la **Lettre de Motivation**, remplacer les placeholders suivants dans le code HTML :
    *   `[Nom de l'entreprise]`
    *   `[Adresse de l'entreprise]`
    *   `[Date]`
    *   `[Intitulé du poste ciblé]`
3.  Dans le **CV**, adapter le titre du poste `Directeur Commercial` ou le résumé si un ciblage technique spécifique est requis.
