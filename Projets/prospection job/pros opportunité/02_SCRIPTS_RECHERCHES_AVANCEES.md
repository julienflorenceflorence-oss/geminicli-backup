## PART 2 : SAVED SEARCHES SETUP (NOTIFICATIONS AUTOMATIQUES)

### **Étape 1 : Créer Saved Search #1 - SporTech**

```
1. LinkedIn.com → Jobs
2. Filtrer selon Search #1 (cf. ci-dessus)
3. En haut à droite : Cliquer « Save Search »
4. Nommer : "SporTech Mgmt Bordeaux" (identifiable)
5. Checkbox : "Get notifications for this search" → ON
6. Fréquence : 
   - Si < 5 offres/semaine = "As soon as posted"
   - Si 5-15 offres/semaine = "Weekly digest"
   - Si 15+ offres/semaine = "Weekly digest"
7. Email : Ton adresse principale
8. Save
```

✅ **Résultat** : Tu recevras emails automatiques dès nouvelle offre

## PART 4 : EMAIL AUTOMATION (ZAPIER / N8N)

### **Option A : Zapier (Simple, SaaS)**

**Cas d'usage** : Auto-log LinkedIn offres → Google Sheet

**Setup** (30 min, €15/mois après essai gratuit) :
```
1. Créer compte Zapier.com
2. Create Zap :
   - Trigger : Gmail → New Email Matching Search (LinkedIn Recruiter alerts)
   - Condition : Email contient "LinkedIn job match"
   - Action : Google Sheets → Add Row
   - Mapping :
     * Email subject → Column B (Titre)
     * Email body → Column J (Notes)
     * Timestamp → Column A (Date)
3. Activate Zap
4. Test : Envoyer email test → Voir dans Sheet

ROI : Gagne 5 min/jour sur data entry
```

**Verdict pour toi** : Worth it si tu souhaites vraiment scale à 50+ offres/semaine

## PART 5 : OPTIMISER LE TAUX DE RÉPONSE

### **Facteur #1 : TIMING (Impact +45% réponse)**

```
❌ MAUVAIS : Envoyer 1 semaine après publication
✅ BON : Envoyer MÊME JOUR de publication

Logique :
- Recruteur vient de poster → Plus de 100 applis potentielles
- Ton message arrive en #1 → Visibilité max
- Window = 12-24h après post

Tactique :
1. Activer notifications LinkedIn Searches (cf. Part 2)
2. Dès email reçu → Aller sur offre directement
3. Message dans les 2-3h si possible
```

### **Facteur #2 : PERSONNALISATION (Impact +30% réponse)**

```
❌ MAUVAIS : 
« Je suis intéressé par ton offre. Je crois que je suis bon fit. 
Parlons ? »

✅ BON :
« Votre offre de Head of Sales (assurance-tech) m'intéresse car 
[1-2 DÉTAILS SPÉCIFIQUES DE LA JD : ex. « vous mentionnez l'enjeu 
d'activation réseaux post-formation »]. C'est exactement ce que j'ai 
fait chez [Ta XP] en [Année], avec [1 CHIFFRE]. Dispo pour 20 min ? »

Règle : 2 min adapter le template = +30% réponse
```

### **Facteur #3 : CREDIBILITÉ (Impact +25% réponse)**

```
✅ PROFIL LINKEDIN COMPLÉTÉ :
- Photo pro ✅
- Titre actualisé ✅
- Résumé avec chiffres ✅
- Expériences détaillées ✅
- Recommendations (même 2-3) ✅

Logique : Recruiter clique ton profil → Sees you're legit → Répond
```

### **Facteur #4 : CALL-TO-ACTION CLAIR (Impact +15% réponse)**

```
❌ FLOU :
« Parlons quand tu veux »
« À bientôt »

✅ SPÉCIFIQUE :
« Dispo pour 15 min jeudi matin ou vendredi après-midi ? »
« Peux-tu me bloquer 20 min cette semaine ? Je suis souple sauf mer. »
« Appelons jeudi 10h ? Sinon quel créneau te convient ? »

→ Réduit "friction" pour recruiter répondre
```

### **Facteur #5 : MULTI-TOUCHPOINT (Impact +40% conversion)**

```
Sequence idéale :

J0 : Premier message → 30% réponse imédiate
J3 : Follow-up (si silence) → 20% réponses supplémentaires
J7 : Follow-up final (si silence) → 10% réponses supplémentaires

Total : ~60% taux réponse (vs 30% sans follow-up)

TEMPLATE Follow-up #1 (J3) :
« Salut [Prénom], pas de news sur ta side ? 
Je suis toujours intéressé par le poste + je crois au fit.
Dis-moi si tu as un créneau dispo. Cheers ! »

TEMPLATE Follow-up #2 (J7) :
« Last touch : Je comprends que tu reçois beaucoup de demandes. 
Je suis vraiment enthousiaste sur ce role et mon profil matche 
bien vos besoins. À bientôt ! »
```

## PART 6 : ANALYSE QUALITATIVE (WEEKLY)

### **Chaque dimanche : Analyser ce qui fonctionne**

```
Questions :

1️⃣ TIMING
Q : Offres envoyées J0 vs J1+ → Quel taux réponse ?
Insight : Si J0 > 40% et J1+ < 20% → Focus sur réactivité

2️⃣ SEGMENT PERFORMANCE
Q : Taux réponse par segment (SporTech vs SaaS vs Assurance) ?
Insight : Lequel performe ? Augmenter focus dessus

3️⃣ TEMPLATES
Q : Quel template génère plus de réponse ?
Insight : Trop long / pas assez perso / mauvaise CTA ?

4️⃣ OBJECTIONS
Q : Quand recruiter dit non, quelle objection ?
Insight : « Vous êtes trop senior » → Réajuster targeting
          « Pas télétravail » → Checker localisation avant message

5️⃣ VOLUME
Q : Ratio messages envoyés / qualifiés ?
Insight : Si 100+ offres sourced mais <5 messages = tu qualifies mal
```

### **Exemple Weekly Log**
```
Semaine du 22/07 :
- Messages envoyés : 8
- Réponses positives : 3 (37.5% rate) ✅
- Segment top : SporTech (50%) > SaaS (33%) > Assurance (0%)
- Template top : SporTech (adapt long) > Assurance (short)
- Objections : Pas de géo-fit (1), Salaire trop faible (1)
- Ajustement semaine pro : Focus SporTech + vérifier salaire dans desc

Semaine du 29/07 :
- Messages envoyés : 10
- Réponses positives : 4 (40% rate) ✅
- Segment top : SporTech (60%) = consistence OK
- Nouvelles insights : Multi-touchpoint donne +15% (J0 vs J3)
- Action : Ajouter follow-up systematic pour toute offre high-match
```

## PART 7 : RED FLAGS À ÉVITER

```
🚩 RED FLAG OFFRE :
- Titre passe-partout ("Commercial H/F" sans secteur clair)
- Description < 200 mots (low effort from recruiter)
- Salaire pas mentionné (salaire très bas probable)
- "Télétravail 100%" (tu veux terrain)
- Offre postée 30j+ ago (déjà pourvue?)
→ Score probablement <75% → Skip

🚩 RED FLAG RECRUITER/RH :
- Profile pic = generic stock photo
- RH name misspelled / looks fake
- Recruiter compte très jeune (< 3 mois)
- Offre copy-paste (même JD 5x dans ses posts)
→ Potentiel scam ou mega-low quality → Skip (ou prudence)

🚩 RED FLAG APRÈS RÉPONSE :
- Recruiter demande argent "frais de dossier"
- Offre trop vague ("earn 10k€/month easily")
- Urgence artificielle ("Must decide today")
→ Scam → Blocker

✅ GREEN FLAG :
- Recruteur répond dans les 6h
- Offre spécifique avec chiffres (salaire, équipe size, secteur)
- RH profile complété, recommendations visibles
- Entretien prévu < 48h
```
