### B. **Méthodologie de Sourcing (3 Niveaux)**

#### **Niveau 1 : Recherche LinkedIn Native (Gratuit, 1h/jour)**

**Étape 1 - Paramétrage Filtre**
```
1. Aller sur linkedin.com/jobs/
2. Filtres appliqués :
   - Intitulé : (Responsable|Head of|Directeur) (Sales|Growth|Commercial|Ventes|Activation)
   - Secteur : SporTech, SaaS, Assurance, Immobilier
   - Lieu : Bordeaux, Toulouse, France
   - Postées : Derniers 7 jours
   - Niveau d'expérience : Senior (10+), Manager
   - Taille entreprise : 20-1000
3. Trier par "Date" (récent d'abord)
4. Parcourir 20-30 offres/jour
```

**Étape 2 - Scoring Rapide (< 2 min/offre)**
```
Pour chaque offre :
- Lire le titre + secteur → Segment 1/2/3/4 ?
- Lire la description (first 200 chars) → Rôle match ? (95%+ go ahead)
- Checker localisation → Bordeaux/Toulouse OK ?
- Skimmer les responsabilités → Management ? CRM/Growth ?
- Résultat : GO (appliquer), MAYBE (sauvegarder), SKIP

Temps cible : 2 min/offre × 25/jour = 50 min/jour
```

**Étape 3 - Sauvegarde Système**
```
Google Sheet (partagée avec toi + potentiel coworker IA) :
- Colonne A : Date trouvée
- Colonne B : Titre + Lien LinkedIn
- Colonne C : Entreprise + Secteur
- Colonne D : Localisation
- Colonne E : Score Match (%) 
- Colonne F : Status (À contacter / Contacté / Réponse / Rejet)
- Colonne G : Notes (objections, leverage, next step)

Objectif : Alimenter 5-10 offres qualifiées/jour en "À contacter"
```

#### **Niveau 2 : LinkedIn Recruiter (Payant, 5 min/jour)**
*Si budget OK (~500€/an) : passer par LinkedIn Recruiter Lite pour accès searches avancées + message free LinkedIn*

**Features + ROI** :
- ✅ Searches illimitées + Boolean operators
- ✅ Messages directs aux candidats (même sans connexion)
- ❌ Coûteux, optionnel
- **Verdict pour toi** : Commencer gratuit, activer si >15 candidatures/mois justifiées

#### **Niveau 3 : Scraping / Outils d'Automation**
*À ÉVITER pour l'instant* (risque LinkedIn ban, temps setup). Lever si Niveau 1+2 saturés (mois 3+).

Julien »
