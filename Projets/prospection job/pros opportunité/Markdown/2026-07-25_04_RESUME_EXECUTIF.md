## 🎲 SCORING DE MATCH (FORMULE SIMPLE)

```
SCORE FINAL (%) = 
  (Secteur × 0.25) +
  (Rôle × 0.30) +         ← CRITIQUE (responsable équipe ?)
  (Management × 0.20) +
  (Tech/CRM × 0.15) +
  (Géo/Salaire × 0.10)

SEUIL GO : ≥ 80% = CONTACTER
SEUIL MAYBE : 70-79% = À EXAMINER
```

## 💡 MASTER KEY INSIGHTS

### **1. Scoring System = Your Filter**

```
80% match = GO
70-79% = Maybe (only if slow week)
<70% = SKIP
→ This saves 80% of your wasted outreach time
```

### **2. Segment Performance Varies**

```
SporTech > SaaS > Assurance > Immobilier
(In taux réponse & enthusiasm)
→ Mois 1 : Focus SporTech 70%, SaaS 20%, Assurance 10%
→ Mois 2 : Rebalance based on data
```

### **3. Multi-Touch Doubles Conversion**

```
1st message : 30% réponse
+ 3-day follow-up : +20%
+ 7-day follow-up : +10%
Total : ~60% taux réponse (vs 30% no follow-up)
```

### **4. Template Matters, But Personalization Wins**

```
Generic template = 10-15% réponse
+ 2-min personalization = +30% → 40-45% réponse
→ Investment : 2-3 min per message = ROI énorme
```

### **5. Network > Cold Outreach**

```
Warm intro (reference) = 50-60% réponse
Cold message = 30-40% réponse
→ Activate your warm network in parallel
```
