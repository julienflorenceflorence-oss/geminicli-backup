## 📞 COMMON QUESTIONS

### **Q : Par où je commence ?**
A : Read 04_RESUME_EXECUTIF.md (5 min), then 01_PLAN_ACTION_OPERATIONNEL.md, then execute PHASE 1.

### **Q : Ça prend combien de temps ?**
A : Setup = 2 heures. Ongoing = 45 min/jour (sourcing + contact). Weekly analysis = 10 min.

### **Q : Quel est le ROI ?**
A : 90 jours → 8+ entretiens → 1-2 offres reçues. Objectif = 1 acceptée.

### **Q : Je peux commencer avec quel budget ?**
A : Zéro. Tout gratuit (LinkedIn native + Google Suite). Optional : LinkedIn Recruiter (€40/mois, Mois 2+).

### **Q : Comment savoir si ça marche ?**
A : Track dans Google Sheet. Reply rate ≥ 30%, Entretiens ≥ 1/week, Offres ≥ 1/mois (Mois 2+).

### **Q : Et si je reçois pas d'offres après 90 jours ?**
A : → 03_CIBLES_PRIORITAIRES.md - Failure recovery protocol. Options : Pivot segment, activate warm network, consider contract/internship.
