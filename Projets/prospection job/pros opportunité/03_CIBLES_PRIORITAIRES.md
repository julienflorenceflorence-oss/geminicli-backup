## FAILURE RECOVERY PROTOCOL

**Si pas d'offre après 12 semaines** :

```
Analysis Questions :
1. Taux réponse vraiment bas ? (<20%)
   → Reprendre templates (trop long? pas perso?)
   → Vérifier profile LinkedIn (professional?)
   
2. Réponses OK mais pas entretiens ?
   → Offres pas assez relevant (criteria trop stricte?)
   → Salaire demandé trop élevé ?
   
3. Entretiens OK mais no offer ?
   → Objection pattern ? (too senior? not tech enough? geo?)
   → Message de suivi trop faible? Negotatiate hard enough?
   
4. Offres mais rejets trop chers ?
   → Réajuster targets (focus SporTech where passion drives negotiation)
   → Consider stepping down 5k salaire si culture fit
   
Pivot Tactic si needed :
- Ajouter « Immobilier » ou autre segment
- Activer warm network (call old colleagues)
- Consider contract / stage if urgent $$ (not ideal but option)
- Leverage « Doinsport » as reference si positive
```
