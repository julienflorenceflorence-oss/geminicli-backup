Configuration Messagerie iCloud

1. Utiliser le mode "Copier-Coller" direct (Recommandé sur Mac)

Le moyen le plus simple sur Mac :

  1. Cliquez sur le bouton vert "Copier dans Apple Mail" dans le Studio.
  2. Ouvrez l'application Mail sur Mac (ou le Webmail iCloud.com).
  3. Créez un nouveau message et faites simplement Cmd + V (Coller). Tout le design GitHub (couleurs, tables, alertes) est conservé !

2. Activer l'envoi SMTP avec le script Python

Pour envoyer des emails automatiquement sans passer par l'application Mail :

  1. Rendez-vous sur appleid.apple.com.
  2. Dans la section Connexion et sécurité, sélectionnez Mots de passe spécifiques à une application.
  3. Générez un mot de passe (ex: abcd-efgh-ijkl-mnop).
  4. Utilisez le script send_icloud_email.py disponible dans le dossier /Python.
