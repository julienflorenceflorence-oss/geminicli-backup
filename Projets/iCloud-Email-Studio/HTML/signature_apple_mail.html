🍎 Mode d'Emploi pour Installer sur Mac (Apple Mail) :

  1. Cliquez sur le bouton ci-dessus "Copier pour Apple Mail (macOS)".
  2. Ouvrez l'application Mail sur votre Mac.
  3. Dans la barre de menu supérieure, allez dans Mail > Réglages... (ou Cmd + ,), puis cliquez sur l'onglet Signatures.
  4. Sélectionnez votre compte (iCloud ou Gmail), puis cliquez sur le bouton + pour créer une nouvelle signature.
  5. Dans la zone d'édition à droite, décochez la case "Toujours utiliser la même police que le message par défaut".
  6. Effacez le texte par défaut, puis faites Cmd + V (Coller).
  7. Fermez la fenêtre des réglages. Votre signature est désormais active et configurée !
